# NPC Village downloads

Ready-to-play builds of [NPC Village](https://github.com/LJAguil/Npc-Village). No Godot needed.

- **Windows:** [NPC-Village-Windows.zip](https://github.com/LJAguil/Npc-Village/raw/downloads/NPC-Village-Windows.zip). Unzip it and double-click **NPC Village.exe**.
  If Windows says "Windows protected your PC", click **More info** and then **Run anyway** (the game isn't signed by a company).
- **Linux:** [NPC-Village-Linux.zip](https://github.com/LJAguil/Npc-Village/raw/downloads/NPC-Village-Linux.zip). Unzip it and run **NPC Village.x86_64**.
